# גבעות עדן — החיים ביישוב

משחק חיים אמיתיים ביישוב גבעות עדן: בונים את היישוב, מגדלים משפחה, הולכים לעבודה ולתפילות, שומרים שבת ומקימים סניף בני עקיבא.
